# 演法 Staging：同一句话，怎么演

做画面之前先读这一页。风格（STYLE-SHEET.md）决定画面"长什么样"，演法决定"怎么演"：这一句话在故事里是干什么的，观众这一秒该看到什么、感觉到什么。演法跟风格无关，三种风格和自定义风格都适用。

"演法"借的是电影里的 staging（场面调度）：同一段台词，放在哪、怎么动、什么时候出，效果完全不同。

## 一句话

**画面上的每一样东西都在帮着讲故事。** 动画少，观众会走神；动画乱，观众会累。两个问题的解法是同一个：每一句都有一个有目的的画面回应，而且每个回应都用一个有名字、调好手感的动作，不临时编。

## 一、密度规则（解决"动画太少"）

1. **每条字幕开始后 0.7 秒内，画面上至少有一处变化。** 暂停在任意一秒，画面都应该和正在说的话对得上。
2. **动作落在词上，不落在秒数上。** 用逐字时间戳，让动作在说到那个词的那一刻出现（例如"说到'漏斗'时，漏斗弹出来"）。写成"第 3 句开始 + 词的偏移"，不要写死"12.4 秒"。配音一改，写死的秒数全部错位。没有逐字时间戳时，按字数估算并在 HANDOFF.md 里注明。
3. **任何场景都不能以空画面开场。** 第 0 帧就要有东西。
4. **这一句没有新东西可演时，就指一下旧东西**：给正在说的词画下划线、圈出来、放大一下，或把别的东西变暗。这已经算一次变化。
5. **超过 3 秒没有任何变化的地方，都要列出来检查。** 写一个小脚本扫时间线（或抽帧对比），把这些"死段"列给创作者，逐个决定是加一拍还是故意留白。
6. **但开场之后要安静下来。** 一句话最多一个"响"的动作。密度靠"每句都有回应"，不靠"每秒都在动"。

## 二、手感规则（解决"动画不好看"）

不好看的动画，九成是这几个问题：全用 linear、时长乱、所有东西同时出、出现和消失用同一种曲线。照下面的表来，不要临时发明缓动曲线：

| 场合 | 缓动 | 时长 | CSS 写法 |
| --- | --- | --- | --- |
| 出现（滑入、淡入） | 快起慢停 ease-out | 0.4–0.9 秒 | `cubic-bezier(.2,.7,.2,1)` |
| 弹出（贴纸、标签、图标） | 带一点回弹 back-out | 0.35–0.5 秒 | `cubic-bezier(.34,1.56,.64,1)` |
| 砸下（盖章、重音字） | 慢起快停 ease-in，落地那一下最快 | 0.2–0.3 秒 | `cubic-bezier(.55,0,1,.45)` |
| 消失、退后 | ease-in，比出现更快 | 0.2–0.3 秒 | `cubic-bezier(.4,0,1,1)` |
| 从 A 移到 B、镜头推拉 | 两头慢中间快 ease-in-out | 0.5–0.8 秒 | `cubic-bezier(.65,0,.35,1)` |
| 数字滚动 | ease-out，最后慢慢停在真实数字上 | 0.8–1.2 秒 | `cubic-bezier(.33,1,.68,1)` |
| 打字、滚动长截图 | 匀速 linear（唯一可以用匀速的场合） | 按长度 | `linear` |

另外几条：

- **错开出现（stagger）。** 一组东西不要同时出，相邻两个间隔 0.08–0.15 秒，从左到右或从上到下。
- **有轻重。** 一个画面里只有一个主角动作，其余要么不动，要么用更小、更短的动作。
- **动得少但动得准，好过一直在动。** 截图匀速慢慢放大几个百分点不算"动"；说到哪里，就推到哪里、圈到哪里。
- **推进去之后要拉出来**，不要连着三次往里推。
- **随时可跳转（seek-safe）。** 渲染器是一帧一帧跳着渲染的：随时间变化的状态，要么每个状态一个元素、到点切换，要么用补间算数值，不要用"到点执行一段代码去改文字"。循环要有限次，随机要固定种子。

每种风格各自的动作清单（名字、表达什么、什么时候用、什么时候别用、参数）见 STYLE-SHEET.md；可以播放的样例见 [examples/moves.html](../examples/moves.html)。

## 三、四个旋钮（解决"一股模板味"）

一个演法由四样东西组成。**相邻两段，至少换两个旋钮。** 只换颜色、不换演法，观众会觉得"又是这一套"，业内叫模板感（template fatigue）。

| 旋钮 | 可选 |
| --- | --- |
| **隐喻**：用什么来演 | 直接摆字 · 一个物件（硬币、门、温度计、杯子）· 一个场景（电梯、地铁、游戏关卡）· 一个过程（长高、灌满、刮开、翻开） |
| **镜头**：画面怎么动 | 不动（让东西自己动）· 慢推进去 · 拉出来看全貌 · 横着扫过去 · 快推（只给重音）· 跟着一个东西走 |
| **构图**：东西放哪 | 左字右图 · 正中一个大东西 · 满屏 · 左右对比 · 跟人发生关系（从人身后、手里、头顶出来） |
| **节奏**：快慢 | 均匀一拍一拍 · 先停住再爆发 · 慢慢长 · 一连串快切 · 留白（静一拍再出） |

## 四、原则

1. **先问节拍，再挑演法。** 这一句是钩子、揭晓还是讲过去？节拍决定该用多大的力。
2. **隐喻从选题里来。** 讲钱就用硬币、账本、小票；讲 app 就用手机、通知、进度条；讲成长就用楼梯、等级。别从别的话题借。
3. **一条视频一个主隐喻贯穿。** 开头立起来的东西，中间反复出现，结尾回来收住。主隐喻统一，局部演法才可以多变。
4. **信息重要就用实的，情绪重要就用虚的。** 要观众记住的数字和步骤，用真截图、真数字；要观众感受的，用隐喻和夸张。
5. **真东西优先。** 每个场景先问：有没有真的东西可以放上来？录屏、真实的 app、真实的聊天、真实的数字，然后才是截图。画出来的动画只做两件事：把真素材串起来（标注、计数、对比、转场），以及展示镜头拍不到的抽象机制。
6. **力气留给高潮。** 一条视频只有一两个大演法，放在钩子和 70–85% 处的高潮。
7. **人是主角。** 出镜的视频里，能跟人发生关系的演法优先：东西从人身后长出来、落在手里、出现在头顶。
8. **0.5 秒看懂。** 观众要想一下才明白的隐喻，换掉。
9. **不重复。** 一条视频里每种演法最多用一次；相邻两段不用同一个镜头动作。

## 五、导演原则（从电影借来的）

1. **能演出来，就别写出来（show, don't tell）。** "赚到钱了"与其打一行字，不如让硬币堆起来。
2. **每一镜回答一个问题。** 答不上"这一镜让观众知道了什么"的镜头，删掉。
3. **景别要变。** 全貌交代在哪，中景讲事，特写给情绪。一直一个景别会闷。
4. **管住观众的眼睛。** 上一镜的重点在画面哪里，下一镜的重点就放在附近，换场才顺。
5. **方向一致。** 东西从右边出去，下一镜就从左边进来；时间轴从左到右表示从过去到未来。
6. **剪在动作上。** 一个东西飞出去，下一镜从另一边飞进来，换场会像一个镜头。
7. **声音先进来。** 下一段的声音比画面早半拍（J-cut）。
8. **反差制造张力。** 快和慢、大和小、安静和爆发，挨着放才有力量。
9. **留一口气。** 重要的一句之后停一拍。不是每一秒都要塞东西。
10. **前面埋的，后面要用上。** 开头出现的东西，结尾要回来；用不上的就别放。

## 六、按节拍挑演法

每个节拍给几种方向，不求全，按选题挑。

| 节拍 | 演法方向 |
| --- | --- |
| **开头钩子** | 结果先摆出来再盖章 · 红笔圈住定格的一帧 · 从一个特写猛地拉出来看全貌 · 前后两个数字左右对比 |
| **介绍自己 / 某人** | 名片从手里弹出来 · 头顶冒出一个标签 · 角色登场卡（名字 + 一句话） |
| **列要点** | 清单逐条打勾 · 便利贴一张张贴上墙 · 抽屉一格格拉开 · 地铁站一站站亮起 · 扑克牌一张张翻开 |
| **揭晓答案 / 关键数字** | 数字滚动后盖章 · 柱子长高 · 硬币堆起来 · 温度计灌满 · 天平倒向一边 |
| **反转** | 你以为 → 其实是（卡片翻面）· 刮刮乐刮开 · 拉开幕布 · 镜头往后拉，原来只是更大东西的一角 |
| **章节切换** | 章节牌（大号数字 + 标题）· 推开一扇门 · 电梯"叮"一下到下一层 · 关卡地图走到第 2 关 · 翻书 |
| **金句** | 一屏一句大字砸下来 · 字被刻进石头 · 霓虹招牌一个字一个字亮起 |
| **讲步骤 / 路线** | 真实录屏 + 光标点击 + 红圈 · 闯关路线 · 小票一行行打印出来 · 乐高一块块拼起来 |
| **成长 / 前后对比** | 左右分屏"以前 / 现在" · 排行榜换位 · 等级条升级 · 同一画面换一套风格 |
| **坚持 / 最后一步** | 进度条卡在 99% · 爬山最后一段 · 电量 1% |
| **讲过去 / 回放** | 画面变旧照片、加颗粒 · 慢动作回放 · 时间轴往回倒 |
| **讲错误 / 崩溃** | 报错弹窗一个接一个 · 东西碎掉 · 前几关秒过，Boss 打不动 |
| **紧迫 / 风险** | 倒计时 · 沙漏 · 红色警报闪一下 |
| **做选择** | 岔路口 · 两个按钮，光标犹豫着移过去 |
| **揭示全貌** | 漏斗：一堆变成一个 · 镜头一路拉远，从一个人拉到一座城 |
| **情绪 / 感动** | 画面安静下来，只剩字 · 颜色慢慢暖起来 · 音乐先停一拍 |

## 七、动画之外的讲故事零件

- **情绪曲线**：钩住 → 安静下来 → 慢慢加码 → 70–85% 处高潮 → 收尾。动画的力气跟着这条线走。
- **声音**：高潮前静一拍，再让音乐和音效一起进。沉默也是声音。
- **颜色剧本**：讲困难时偏冷，讲突破时变暖，都在同一套色板里变。
- **剪辑本身**：推近人脸是最强的强调，跳切和停顿也是节奏，不全靠动画。
- **字幕**：关键词变色、变大，跟着情绪走。

## 八、agent 怎么用这一页

1. 看选题，定**一个主隐喻**，写在分镜表最上面。
2. 每一句标一个**节拍**，从第六节挑演法。
3. 分镜表加两列：「演法」（四个旋钮各选了什么）和「动作」（从风格的动作清单里挑，写上落在哪个词）。检查相邻两段至少换了两个旋钮。
4. 全片只给一两个节拍用大演法，其余克制。
5. 写完场景跑一遍密度检查：每条字幕 0.7 秒内有没有变化，有没有超过 3 秒的死段，有没有空画面开场。
6. 抽帧检查：每隔约 2.5 秒抽一帧拼成一张联系表（`ffmpeg -vf "fps=1/2.5,scale=400:-1,tile=6x6"`），看动画进行到一半时的样子，而不只是每段结尾的定格。
7. 动作清单里没有的动作，先在分镜里写清楚，给创作者看过再做；做出来创作者认可的，补进 STYLE-SHEET.md 的动作清单，下次直接用。
